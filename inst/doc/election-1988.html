1988 Presidential Election: Data Preparation

Preparation scope

This article documents the changes implemented for the 1988 presidential election. It preserves the exact capitalisation of the labels used in that script. Replacement values and source findings have not been independently verified for this documentation.

Postal registered-elector rows

Removed No of Registered Electors rows for Postal District Votes where the count is missing.

Missing vote counts and associated percentages

Where Votes is missing, Percentage is set to zero unless the row is Total No of Votes Polled. All remaining missing vote counts are then replaced with zero. This rule is based on missing counts; it does not fill every missing percentage.

Checks and documentation limits

The Baddegama comment mentions 49,613 polled votes, but the formula uses 49,163. This conflict should be resolved against the source before claiming the replacement percentage is verified.

The national reference figures written in the script also require review: candidate figures sum to 5,094,757 against stated valid votes of 5,094,775. Stated valid votes plus rejected votes sum to 5,186,220 against stated total polled votes of 5,186,277. These observations concern the script’s written reference figures.
